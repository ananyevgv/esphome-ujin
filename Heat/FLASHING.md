# 🔧 Инструкция по прошивке термостата EH-WB (ESP32) через UART

Пошаговая инструкция по считыванию заводской прошивки и записи ESPHome
с учётом всех нюансов из документации проекта
[`ananyevgv/esphome-ujin`](https://github.com/ananyevgv/esphome-ujin/tree/main/Heat).

---

## ⚠️ Шаг 0: Важные предупреждения из ReadMe

Перед началом обязательно учтите два момента:

1. **Сделайте резервную копию** — в ReadMe сказано:
   > «Перед прошивкой на ESPHome обязательно посмотрите LOG устройства и сделайте резервную копию (backup)».
2. **Питание 3.3В** — в ReadMe сказано:
   > «На некоторых платах нет линейного стабилизатора 3.3В — он установлен в ответной части. При прошивке требуется подача 3.3В. или подключение ответной части».

   Это значит, что ваш USB-UART программатор должен выдавать **3.3В**, и вы должны подать это питание на плату.

---

## 📥 Шаг 1: Считывание заводской прошивки (бэкап)

Это критически важный шаг, чтобы иметь возможность вернуть устройство в исходное состояние.

1. **Подключите USB-UART программатор** к контактам ESP32 на плате термостата:

   | Программатор | Плата термостата |
   | :--- | :--- |
   | GND | GND |
   | TX | RX (обычно `GPIO3`) |
   | RX | TX (обычно `GPIO1`) |
   | 3.3V | 3.3V |

2. **Переведите ESP32 в режим загрузчика**: зажмите кнопку **BOOT** (или замкните `GPIO0` на GND) и кратковременно нажмите **RESET**.

3. **Считайте дамп** с помощью `esptool.py`. Для ESP32-PICO-V3-02 с 8 МБ флеш-памяти (стандартный объём для этой модели) команда будет такой:

   ```bash
   esptool.py --port COM4 read_flash 0x0 0x800000 factory_backup.bin
   ```

   * Замените `COM4` на ваш порт.
   * `0x800000` — это 8 МБ. Если у вас 4 МБ, используйте `0x400000`.

## 📝 Шаг 2: Подготовка конфигурации ESPHome

1. **Скачайте файлы проекта**: перейдите в папку [`Heat`](https://github.com/ananyevgv/esphome-ujin/tree/main/Heat) в репозитории `ananyevgv/esphome-ujin` и скачайте основной YAML-файл (например, `heat.yaml`).

2. **Создайте устройство в ESPHome**: в Home Assistant откройте панель ESPHome, нажмите **NEW DEVICE**, создайте пустое устройство и назовите его (например, `ujin-heat`).

3. **Вставьте конфигурацию**: откройте скачанный YAML-файл из репозитория и скопируйте его содержимое в редактор ESPHome, заменив сгенерированный код.

4. **Настройте `secrets.yaml`**: убедитесь, что в вашем файле `secrets.yaml` (в папке `/config/esphome/`) указаны корректные данные Wi-Fi. Если их нет, добавьте:

   ```yaml
   wifi_ssid: "Ваш_SSID"
   wifi_password: "Ваш_пароль"
   ```

> **Примечание:** в ReadMe указано, что требуется **ESPHome 2026.4+**, поэтому убедитесь, что ваш аддон обновлён.

## ⚡ Шаг 3: Прошивка устройства

Теперь можно записывать свою прошивку.

### Способ А: Через веб-интерфейс ESPHome (рекомендуемый)

1. В панели ESPHome на карточке вашего устройства (`ujin-heat`) нажмите **INSTALL**.
2. Выберите вариант **Plug into the computer running ESPHome Dashboard** (или «Подключить к компьютеру с ESPHome»).
3. В выпадающем списке выберите COM-порт вашего USB-UART программатора.
4. Нажмите **INSTALL**. ESPHome скомпилирует прошивку и зальёт её в устройство.

### Способ Б: Через командную строку

Если вы предпочитаете CLI, можно использовать `esphome run`, который сам всё скомпилирует и прошьёт:

```bash
esphome run heat.yaml --device COM4
```

* Замените `heat.yaml` на имя вашего файла, а `COM4` — на ваш порт.

### Если прошивка не идёт

* **Снизьте скорость**: некоторые USB-UART переходники (CH340, CP2102) нестабильно работают на высоких скоростях. Попробуйте снизить скорость в YAML-файле, добавив строку:

  ```yaml
  upload_speed: 115200
  ```

* **Проверьте питание**: ещё раз убедитесь, что на плату подаётся **3.3В**, как указано в ReadMe.

---

## ✅ Шаг 4: После прошивки

1. Отключите программатор от платы.
2. Нажмите кнопку **RESET** на устройстве (или выключите/включите питание).
3. Устройство должно подключиться к вашей Wi-Fi сети и автоматически обнаружиться в Home Assistant через интеграцию ESPHome.
4. Все последующие обновления можно будет делать **по воздуху (OTA)** — без проводов.
